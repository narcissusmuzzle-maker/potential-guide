Luv Sync 0.2.0 — фоновая служба для Amazfit Bip Max: кладёт цвета полосок в общую память часов, циферблат Luv Face их читает.

ЧТО ИЗМЕНИЛОСЬ В 0.2.0
Раньше циферблат сам запускал Luv Sync при каждом включении экрана, и приложение оставалось открытым поверх циферблата. Это убрано:
- Циферблат (Luv Face 0.3.0) больше НИЧЕГО не запускает, только читает цвета.
- Luv Sync теперь фоновая служба (app-service/sync.js) без экрана. Она работает после выхода из приложения и раз в минуту
  записывает цвета (сразу при запуске — один раз).
- Страница приложения — только панель управления. Её надо открыть ОДИН раз вручную (из списка приложений), чтобы запустить службу.

КАК ЭТО РАБОТАЕТ
Цвета пишутся в общую память часов двумя каналами: ShareTypedStorage и ShareLocalStorage (@zos/storage, ключ luv_c).
Циферблат читает их через TypedStorage / LocalStorage из @zos/share-storage (по appId Luv Sync, 1072512).
ПРОТОТИП: цвета пока придуманные (shared/testdata.js), с каждой записью другие — чтобы было видно, что обновление дошло.
Настоящие цвета (как у виджета статистики) будет присылать телефон — следующий шаг.
Приложения «Таймер» и LuvU613 (телефон) этот проект не трогает.

КАК УСТАНОВИТЬ (так же, как раньше)
1. НОВЫЙ репозиторий на GitHub (не тот, где циферблат), загрузить в него ВСЁ из этой папки.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Settings -> Pages: публикация из ветки gh-pages. Вкладка Actions: дождаться зелёной галочки.
3. QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Старую версию Luv Sync с часов лучше удалить: у новой другой состав (есть служба).

ПРОВЕРКА
1. Откройте Luv Sync из списка приложений. Если часы спросят разрешение на фоновую работу — разрешите.
   На экране должно быть: «Служба: работает», «Каналы: typed+local» (или typed / local), «Запись № N, X с назад».
   Кнопки: «Запустить службу», «Остановить», «Записать сейчас» (разовая запись без службы).
2. Выйдите на циферблат. Через минуту после включения экрана строка под полосками (n=… res=… age=…) должна показывать рост n,
   age не больше ~60 s, статус ok, а цвета полосок должны меняться.
Если экран приложения ПУСТОЙ (даже нет слова «Luv Sync…») — страница не загрузилась вообще; пришлите, что было на часах.
Если что-то из этого не так — пришлите, что написано на экране приложения (все строки) и строку под полосками на циферблате.

ВАЖНО (ограничения Zepp OS)
- Постоянно работать может только одна фоновая служба; если у другого приложения тоже есть служба, система может показать выбор.
- Служба видна в списке работающих служб системы; остановить можно кнопкой «Остановить».
- Раз в минуту — это для прототипа. Когда будут настоящие данные, частоту подберём.

ГДЕ ЧТО МЕНЯТЬ
app-service/sync.js — что служба делает при запуске и каждую минуту.
shared/store.js     — как и куда пишутся цвета.
shared/link.js      — ключи общей памяти и формат записи (такой же файл в проекте Luv Face; менять только в обоих сразу).
page/index.js       — панель управления.
